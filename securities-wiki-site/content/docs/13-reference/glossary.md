# Từ điển Việt–Anh cho team

> Bản đào tạo 1.0 • Rà soát: 07/11/2026 • Mức độ: Nền tảng → nâng cao  
> Phạm vi: kiến thức và thiết kế tham chiếu; ví dụ số liệu là giả lập. Quy tắc có ngày hiệu lực được quản lý riêng.


| Thuật ngữ | Giải thích ngắn |
|---|---|
| Security / chứng khoán | Công cụ chứng khoán; khác security nghĩa an toàn thông tin. |
| Equity / cổ phiếu, vốn chủ | Dùng đúng nghĩa theo ngữ cảnh sản phẩm hay kế toán. |
| Bond / trái phiếu | Công cụ nợ có điều kiện thanh toán. |
| Issuer / tổ chức phát hành | Chủ thể phát hành công cụ. |
| Primary market | Thị trường sơ cấp. |
| Secondary market | Thị trường thứ cấp. |
| Listing / niêm yết | Trạng thái/quy trình niêm yết theo điều kiện. |
| Exchange / sở giao dịch | Tổ chức/vận hành thị trường theo phân công. |
| Broker | Đơn vị/người thực hiện dịch vụ môi giới theo vai trò. |
| Custodian | Tổ chức cung cấp dịch vụ lưu ký theo tư cách. |
| Depository / CSD | Hạ tầng lưu ký chứng khoán tập trung. |
| Clearing | Xác định, đối chiếu, quản lý nghĩa vụ bù trừ. |
| Settlement | Hoàn tất chuyển giao tiền/chứng khoán. |
| CCP | Đối tác bù trừ trung tâm theo cơ chế pháp lý. |
| DvP | Giao chứng khoán gắn với thanh toán tiền. |
| Order | Ý định giao dịch gửi theo quy tắc. |
| Trade / execution / fill | Giao dịch hoặc phần thực hiện của lệnh; kiểm tra ngữ nghĩa từng API. |
| Order book | Sổ lệnh mua/bán đang chờ. |
| Bid / ask | Giá mua / giá bán. |
| Spread | Chênh lệch giá bán và mua tốt nhất trong ví dụ thông thường. |
| Tick size | Đơn vị yết giá. |
| Lot size | Đơn vị khối lượng giao dịch. |
| Odd lot | Lô lẻ theo quy định thị trường. |
| Auction | Khớp định kỳ/đấu giá theo ngữ cảnh. |
| Continuous matching | Khớp liên tục. |
| Negotiated trade | Giao dịch thỏa thuận. |
| Price-time priority | Ưu tiên giá rồi thứ tự thời gian theo quy tắc. |
| Partial fill | Khớp một phần. |
| Leaves quantity | Khối lượng còn làm việc của lệnh theo định nghĩa API. |
| Cumulative quantity | Khối lượng khớp tích lũy. |
| VWAP | Giá bình quân gia quyền theo khối lượng. |
| OHLC | Giá mở, cao, thấp, đóng. |
| NAV / iNAV | Giá trị tài sản ròng / giá trị chỉ báo theo sản phẩm. |
| OMS | Hệ thống quản lý vòng đời lệnh. |
| RMS | Hệ thống quản lý/kiểm soát rủi ro. |
| EMS | Hệ thống hỗ trợ thực thi giao dịch; phạm vi tùy sản phẩm. |
| MDDS / market data | Dịch vụ/hệ thống phân phối dữ liệu thị trường; tên gọi cần mapping cụ thể. |
| STP | Xử lý xuyên suốt ít thao tác thủ công. |
| Gateway / adapter | Thành phần chuyển đổi và giao tiếp với đối tác. |
| Acknowledgement / ACK | Xác nhận ở một lớp; không mặc nhiên là đã khớp. |
| Reject | Từ chối; phải biết từ chối lệnh hay yêu cầu sửa/hủy. |
| Heartbeat | Bản tin/tín hiệu kiểm tra phiên theo giao thức. |
| Sequence gap | Thiếu thứ tự bản tin trong phạm vi sequence. |
| Snapshot / delta | Ảnh trạng thái / thay đổi so với trạng thái. |
| Idempotency | Áp dụng lại cùng ý định không tạo thêm tác động nghiệp vụ. |
| Outbox / inbox | Mẫu lưu ý định phát / ghi nhận sự kiện nhận để xử lý bền vững. |
| Ledger / subledger / GL | Sổ ghi nhận / sổ chi tiết / sổ cái tổng hợp. |
| Reservation / hold | Phần tài sản dành cho một nghĩa vụ/ý định có kiểm soát. |
| Buying power | Sức mua theo policy và trạng thái tài sản. |
| Withdrawable | Phần tiền được phép rút. |
| Collateral / haircut | Tài sản bảo đảm / mức khấu trừ khi định giá. |
| Margin call / force sell | Yêu cầu bổ sung/khắc phục / xử lý bán theo điều kiện cho phép. |
| Corporate action | Sự kiện quyền/thay đổi của tổ chức phát hành. |
| Ex-date / record date | Ngày không hưởng quyền / đăng ký cuối cùng. |
| Reconciliation break | Chênh lệch đối soát cần xử lý. |
| Maker-checker | Người lập và người kiểm tra/phê duyệt tách biệt. |
| Information barrier | Kiểm soát ngăn sử dụng/truy cập thông tin gây xung đột. |
| SLI / SLO / SLA | Chỉ số đo / mục tiêu / thỏa thuận mức dịch vụ. |
| RTO / RPO | Mục tiêu thời gian phục hồi / mục tiêu điểm phục hồi dữ liệu. |
| BCP / DR | Liên tục kinh doanh / khôi phục thảm họa. |
| Fencing | Ngăn writer cũ tiếp tục ghi sau chuyển quyền. |
| ADR | Bản ghi quyết định kiến trúc và trade-off. |
| Cutover / rollback | Chuyển vận hành / quay lại theo kế hoạch hợp lệ. |
| Business date / value date | Ngày nghiệp vụ / ngày giá trị của giao dịch. |
| NFR | Yêu cầu chất lượng hệ thống ngoài chức năng thuần túy. |
